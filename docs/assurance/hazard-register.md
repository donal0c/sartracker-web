## Register disposition

This baseline contains confirmed controls, lower-tier evidence, explicit
residuals, and rewrite-pending boundaries. It does not certify the application
for field use. The five absolute blockers remain release-blocking regardless of
the primary gap label on an individual row.

The exact post-PR5 procedure in the charter is mandatory. PR6 then remains the
prerequisite for streamed archive/restore resilience work; neither current-base
archive tests nor PR5 ancestry can substitute for that implementation and its
own exact-head qualification.
